# 📸 Instagram Automation Using Python

This project demonstrates how to automate basic Instagram activities using **Python** and the **Instabot** library.  
It is intended for **educational purposes only** to understand automation, APIs, and Python scripting.

---

## ⚠️ Disclaimer (Important)
This project is created **for learning and demonstration purposes only**.  
Automating Instagram actions may violate Instagram’s Terms of Service.  
Use responsibly and at your own risk.

---

## 🚀 Features

- Instagram login automation
- Follow and unfollow users
- Upload photos with captions
- Send direct messages to multiple users
- Fetch followers and following lists
- Retrieve user profile information

---

## 🛠️ Technologies Used

- Python 3
- Instabot Library
- Instagram API (via Instabot)
